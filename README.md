# Portfolio — Local Preview

This is a minimal portfolio generated for Abhishek Kumar.

Preview locally:

1. Open `index.html` in your browser (double-click or `File → Open`).
2. For a printable resume, open `resume.html` and use `Print → Save as PDF`.

Files added:
- `index.html` — main page
- `resume.html` — printable resume
- `assets/css/styles.css` — main stylesheet
- `assets/js/main.js` — interaction scripts
- `assets/favicon.svg` — favicon

Add your profile photo:

1. Save your image to `assets/images/profile.jpg` (recommended size: 400×400, square).
2. The site will automatically use it in the header, About, Projects and Contact pages. If the file is missing, the initials avatar is shown as a fallback.
